# Visual story assets

Generated with the built-in image generation tool on 2026-10-30. These are
fictional photographic scenes, not photos of a customer or a live app result.
The base frame was generated first; subsequent frames edit that same base to
preserve the person's identity, room, camera, and light. No external API key or
paid video service was configured. No third-party stock imagery was copied.

Final source assets are in `apps/web/public/story/`. Next Image serves responsive
optimized variants; all words and state labels are accessible HTML, not bitmap
text. Keep generated originals unchanged when updating the story.
