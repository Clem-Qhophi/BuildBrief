# Roadmap (P2 — post-hackathon, preserved not built)

Full product vision from `MASTER_BLUEPRINT.md` §§6, 22. Nothing here is in the Nov 4 submission.

- **Capture**: imports (GitHub Issues, Linear/Jira, Slack, docs, voice), stakeholder timeline,
  feature intent graph, multi-project policy templates.
- **Verify**: static-dataflow analysis, CI import, isolated integration tests, staging/browser traces,
  deployment mapping, GraphQL/schema tracing, SBOM + dependency policy (signals, not scanners).
- **Correct**: cross-agent prompt optimization, impact simulator, auto-created PR plans (never
  auto-executed), test generation behind human approval, decision records.
- **Understand**: interactive diagrams, scenario simulator (synthetic-labeled), bug-lab sandbox,
  flashcards/spaced repetition, handover export, incident flashbacks, opt-in Explanation Gate,
  personalized recommendations, progress digests, mobile companion.
- **Transfer/governance**: role/project policies, dependency + ownership maps, onboarding checklists,
  in-app review trail, change approvals, team risk review, release/support readiness.
- **Ecosystem**: daily/weekly digests (opt-in), Slack/email, browser extension, GitHub checks, MCP
  ecosystem, OAuth connectors, API/SDK, multi-repo/multi-language, enterprise tenancy, usage/billing.
- **Business**: solo → indie → team → agency → enterprise ladder; pricing only after
  willingness-to-pay interviews + measured inference cost.
